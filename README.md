# ContactHub

A responsive contact manager with create, search, edit, delete, favorites, emergency contacts, and browser-local persistence.

## Run locally

Open \`index.html\` in a browser. Keep the \`bootstrap\` and \`images\` folders in their existing paths.

## Data and privacy

Contacts are saved in this browser using localStorage. They stay on this device and are not sent to a server. Clearing browser storage removes them. Use the same browser and device to see them again.
